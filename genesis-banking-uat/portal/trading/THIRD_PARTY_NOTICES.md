# NautilusTrader

The runtime installs **nautilus_trader 1.231.0**, published by Nautech Systems Pty Ltd., from PyPI. The package is unmodified and imported dynamically by AVIS's separate Python process.

- Source: https://github.com/nautechsystems/nautilus_trader
- Package and release files: https://pypi.org/project/nautilus_trader/1.231.0/
- License: GNU Lesser General Public License, version 3 or later (LGPL-3.0-or-later).
- License text: https://www.gnu.org/licenses/lgpl-3.0.html

The installed distribution retains its own copyright/license metadata. Users can replace the dynamically imported package with a compatible build, including their own modifications. `requirements.txt` records the exact tested runtime dependencies. AVIS strategy, IPC and banking adapters are separate source files.
