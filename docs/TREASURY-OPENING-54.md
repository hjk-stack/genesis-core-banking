# Treasury opening #54

Owner-directed internal registration of the four existing asset positions. The release process updates only the existing AVISPay UAT app, executes the idempotent booking in that application, and reads the new Treasury positions through the authenticated admin view. The independent 4.5 million GENESIS notes are not included. This is not an external securities transfer, bank payment or blockchain transaction. All booking IDs and source references remain immutable.

The new Treasury positions section is in Administration's Portfolio management page. No additional server is created. The initial-positions register and the original source history are distinct; issuer trade/settlement processing is not part of this milestone.
